# Clash Images Voting App
**Clash** is a fun and interactive web app where users can post two images, sparking exciting debates and letting others vote on their favorite in real-time! Alongside voting, users can share their thoughts and engage in lively discussions by commenting on each Clash.

## 🚀 Features
- **Post a Clash**: Upload two images and let the world decide which one wins!
- **Real-Time Voting**: See votes updated live as users choose their favorite.
- **Comment on Clashes**: Share your opinion and join the conversation.
- **Responsive Design**: Seamless experience on desktop and mobile devices.
- **Dynamic UI**: Live updates for votes and comments without refreshing the page.
